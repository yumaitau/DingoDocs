# Report code font

Noto Sans Mono Regular, from the [Noto project](https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf), licensed under the bundled SIL Open Font License. Embedded in PDF command blocks to preserve selectable Latin, Greek and Cyrillic text and terminal punctuation. Other scripts may require a font with additional glyph coverage; inspect exported PDFs before submission.
