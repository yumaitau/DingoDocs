# Security Policy

Do not open a public issue for a suspected vulnerability. Send a concise report to the security contact configured by the project maintainers, including the affected version, impact, reproduction steps, and any suggested mitigation. Avoid accessing data that is not yours, disrupting deployments, or publishing details before a fix is available.

Maintainers should acknowledge reports within five business days, provide status updates during investigation, and coordinate disclosure after a supported release is available. Good-faith research that respects these boundaries is welcomed.
